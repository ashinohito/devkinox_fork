# ふたつの更新API

一覧しているレコードを対象に、2種類のAPIで一括更新できます。Webhook発火の有無など、用途に応じて使い分けられます。

## 使い方

1. アプリの`一覧画面`を開いた状態で`ふたつの更新API`を選択

2. ダイアログが表示されます。更新方法を選択してください。

   - **一括更新 (records.json)**: 高速に一括更新します（Webhookは発火しません）
   - **個別更新 (record.json)**: 1件ずつ更新します（Webhookが発火します）

3. 更新するフィールドを選択して実行します。

### 回数制限モード

個別更新では「回数制限モード」を有効にできます。

- 60件ごとに1分間の待機を行います
- Webhook回数制限（1分間に60回まで）を超えないように制御します

## APIの違い

| 項目 | records.json（一括更新） | record.json（個別更新） |
|------|-------------------------|------------------------|
| Webhook | 発火しない | 発火する |
| 通知 | 送信されない | 送信される |
| 処理速度 | 高速（最大100件/回） | 低速（1件/回） |

## 注意事項

> [!NOTE]
> Webhook回数制限は1分間に60回までです。61回目以降のWebhookは送信されません。

> [!NOTE]
> ゲストスペースのアプリは現行バージョンでは非対応です。

> [!WARNING]
> 一覧画面で絞り込みを行っている場合、絞り込まれたレコードのみが更新対象となります。
