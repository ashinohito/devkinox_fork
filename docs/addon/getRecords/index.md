# 複数のレコードを取得

レコードのデータを取得して json 形式で確認できます。

## 使い方

1.  アプリの`一覧画面`、`詳細画面`のいずれかを開いた状態で`複数のレコードを取得`を選択

    <img src="./images/select_getrecords.png" alt="選択画像" style="border: 1px solid #e0e0e0;" />

<br>

2.  データの取得条件を設定してください。`検索クエリ`欄に設定したクエリの条件でデータを取得します。

<img src="./images/setting.png" alt="設定" style="border: 1px solid #e0e0e0;" />

> [!TIP]
> kintone Rest API の`/k/v1/records`のクエリにそのまま設定しています。

<br>

3. レコードの情報が json 形式で表示されます。

   <img src="./images/resutl.png" alt="結果画面" style="border: 1px solid #e0e0e0;" />

## 注意事項

> [!NOTE]
> ゲストスペースのアプリは現行バージョンでは非対応です。
