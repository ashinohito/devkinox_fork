# 複数のレコードを取得

レコードのデータを取得して json 形式で確認できます。

## 使い方

1.  アプリの`一覧画面`、`詳細画面`、`編集画面`のいずれかを開いた状態で`複数のレコードを取得`を選択

    ![選択画像](./images/select_getrecords.png "選択画像")

2.  データの取得条件を設定してください。`検索クエリ`欄に設定したクエリの条件でデータを取得します。

![設定](./images/setting.png "設定")

> [!TIP]
> kintone Rest API の`/k/v1/records`のクエリにそのまま設定しています。

3.  ![選択画像](./images/resutl.png "選択画像")

## 注意事項

> [!NOTE]
> ゲストスペースのアプリは非対応です。
